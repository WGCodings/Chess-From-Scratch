# Chess From Scratch

Chess From Scratch lets you build your own chess engine by putting blocks together, a bit like Scratch. Every block is real Rust code. When you are happy with your engine, you download it as a normal Rust project, build it, and play against it. The [desktop app](The-Desktop-App) builds and runs it for you.

You don't need to know Rust to start. You will pick it up on the way, one block at a time.

## Where to start

- **Never made an engine before?** Follow [Your first engine](Your-First-Engine). It takes about ten minutes. (The same steps are in the app: click **Tutorial** at the top.)
